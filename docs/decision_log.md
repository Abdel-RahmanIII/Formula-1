This log records all key architectural, scope, cleaning, feature-engineering, and modeling decisions across Milestone 1. Every judgment call is documented with its rationale, owner, and supporting evidence.

| **DEC-001** | 2026-10-08 | Shared Setup | All | Set global random seed to `42`. | Ensures deterministic behavior across NumPy, Scikit-Learn, and neural network training for perfect reproducibility across team members and Kaggle runs. | **Approved** |

Target is binary: $1$ if `positionOrder <= 3`, $0$ otherwise (podium base rate $\approx 15\%$). Identifiers (`raceId`, `driverId`, `constructorId`, `date`, `year`) are retained for lineage but excluded from training features. | **Approved** |
| **DEC-006** | 2026-10-08 | Environment | M1 | Multi-environment dataset path resolution (Kaggle `/kaggle/input/...` falling back to local `./archive`). | Allows the exact same notebook to be executed seamlessly on local developer workstations and on Kaggle without requiring manual code modifications. | **Approved** |
| **DEC-007** | 2026-10-08 | Analytics / Viz | M2 | Standardized Seaborn/Matplotlib visualization style and automated figure saving to `figures/`. | Enforces visual consistency across all EDA, DE question answers, ablation studies, and XAI figures. High-resolution exports (300 DPI) feed directly into the final PDF report. | **Approved** |
| **DEC-008** | 2026-10-08 | Scope / Cleaning | M1 | Shared-Drive Deduplication Rule on `(raceId, driverId)`. | Raw `results.csv` contains 176 duplicate `(raceId, driverId)` rows from 1950–1978 where drivers shared cars. Rule: prioritize car the driver actually started in (`grid > 0`), breaking ties with best finishing order (`positionOrder`). Preserves 100% uniqueness without losing primary race performance. **Measured 2026-10-12:** the 176 figure counts rows *involved* (85 groups); the surplus is 91 rows raw and 64 rows (61 groups, 1950–1964) after scope filtering. All remaining shared-drive rows hold a grid slot, so `positionOrder` decides every group. Fifteen races keep more than three podium rows because two drivers were classified in the same podium car. | **Approved** |
| **DEC-009** | 2026-10-12 | Scope / Cleaning | M1 | Non-starter rule: drop a `results` row when `laps == 0` **and** (`positionText` in `{F, W}` **or** `status` in `{Did not qualify, Did not prequalify, Withdrew}` **or** `grid == 0`). | Non-starters are known before lights out and cannot podium. Labels alone are unreliable: 24 rows labelled `Withdrew` / `Did not qualify` completed racing laps (one finished 4th), and 173 flagged rows hold a grid slot, so neither the label nor `grid > 0` is a safe test by itself. Requiring zero laps keeps everyone who took the start, including opening-lap retirements from a grid slot. Removes 1,715 rows (1,367 `F`, 331 `W`, 17 excluded / disqualified / did-not-start entries with no grid slot) and no podium finisher. | **Proposed** |
| **DEC-010** | 2026-10-12 | Scope / Cleaning | M1 | Pit-lane starts: after DEC-009, every remaining `grid == 0` row gets `pit_start = 1` and `grid` recoded to the last occupied grid slot of that race + 1. | After DEC-009 the remaining `grid == 0` rows are 72 entries from 2015–2024, all with racing laps completed: genuine pit-lane starts. Left as `0`, an ordinal model would read them as better than pole. Pit-lane starters in the same race tie on the recoded value; `pit_start` keeps them distinguishable. None of the 72 finished on the podium. | **Proposed** |
| **DEC-011** | 2026-10-12 | DE Questions | M2 | Q1 compares 2003–2013 with 2014–2024, for both the grid-based and the qualifying-based front row. A circuit is ranked only with $\ge 10$ front-row starts in each era. | `qualifying.csv` has no rows before 1994 and covers only 1–10 of 16–17 races per season in 1996–2002; it is complete from 2003. Using 2003–2013 keeps both definitions on the same races and gives 11 seasons on each side of 2014. A grid fallback for missing qualifying was rejected: it would force the qualifying-vs-grid gap to zero. The filter applies inside Q1 only; `clean_df` is unchanged. 14 circuits pass the threshold under either definition. | **Approved** |
| **DEC-012** | 2026-10-12 | DE Questions | M2 | Q2 home race = `circuits.country` is one of the countries mapped from `drivers.nationality` (`NATIONALITY_TO_COUNTRIES`). | Country names follow `circuits.country` (`British` → `UK`, `American` → `USA`); `United States` is folded into `USA`. `Monegasque` → `Monaco`, `East German` → `Germany`. Dual nationalities (`American-Italian`, `Argentine-Italian`) have two home countries. `Argentinian ` is stripped of its trailing space. Fourteen nationalities (e.g. Finnish) have no circuit in the data and are always "away"; restricting to drivers with a home race leaves the result unchanged (odds ratio 0.94 vs. 0.95). 1,930 of 24,575 starts are home starts. | **Proposed** |
| **DEC-013** | 2026-10-12 | DE Questions | M2 | Q3 status mapping to *finished / mechanical / accident-driver / regulatory-other*, with a strict rule for mechanical: the label must name a failed car component or system. Minimum 40 starts per constructor per era. | Follows the brief's definition ("failed car component"). Generic `Retired` and `Withdrew`, tyre and puncture labels, `Out of fuel`, `Damage` and `Debris` go to regulatory/other. All 139 statuses are mapped (asserted): 34 finished, 71 mechanical, 12 accident/driver, 22 regulatory/other. Sensitivity run counting `Retired` (49 rows from 2014) as mechanical: ranking unchanged at the top in 2014–2021 ($\rho = 0.97$); Alfa Romeo stays first in 2022–2024 but lower ranks move ($\rho = 0.66$). | **Approved** |
| **DEC-014** | 2026-10-12 | DE Questions | M2 | Q3 ranks constructors as named in the data; a second view merges renamed teams (`CONSTRUCTOR_LINEAGE`) to compare the same team across eras. | The question asks about constructors, so the main answer keeps `constructorId` as-is. Only 8 names exist in both eras, so the cross-era comparison merges Toro Rosso / AlphaTauri / RB, Force India / Racing Point / Aston Martin, Lotus F1 / Renault / Alpine, Sauber / Alfa Romeo and Marussia / Manor. The grouping is a judgment call that is not in the data, which is why it is a check and not the main answer. | **Approved** |

## Detailed 14-Table Leakage Audit (DEC-004 Reference)

| Table | Total Columns | Pre-Race Temporal Status | Pre-Race Safe Columns | Blacklisted / Target / In-Race Columns | Notes & Hazards |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `circuits` | 9 | **Fully Pre-Race Safe** | `circuitId`, `circuitRef`, `name`, `location`, `country`, `lat`, `lng`, `alt` | None | Static track properties and geographic location. |
| `constructors` | 5 | **Fully Pre-Race Safe** | `constructorId`, `constructorRef`, `name`, `nationality` | None | Static constructor properties. |
| `drivers` | 9 | **Fully Pre-Race Safe** | `driverId`, `driverRef`, `number`, `code`, `forename`, `surname`, `dob`, `nationality` | None | Static driver demographics; `dob` used with race date to calculate pre-race age. |
| `seasons` | 2 | **Fully Pre-Race Safe** | `year` | None | Calendar year. |
| `races` | 18 | **Fully Pre-Race Safe** | `raceId`, `year`, `round`, `circuitId`, `name`, `date`, `time`, all session dates/times (`fp1_date`, ..., `quali_date`, `sprint_date`) | None | Official scheduled calendar metadata. |
| `qualifying` | 9 | **Fully Pre-Race Safe** | `qualifyId`, `raceId`, `driverId`, `constructorId`, `number`, `position` (as `quali_position`), `q1`, `q2`, `q3` | None | Concluded before race start. **Naming Rule:** Rename `position` to `quali_position` to avoid collision with `results.position`. |
| `results` | 18 | **Hybrid (Leakage Core)** | `constructorId`, `number`, `grid` | **Target:** `positionOrder <= 3`<br>**Blacklisted:** `position`, `positionText`, `points`, `laps`, `time`, `milliseconds`, `fastestLap`, `rank`, `fastestLapTime`, `fastestLapSpeed`, `statusId` | Contains the actual race outcome! Only starting `grid` (and metadata) is known pre-race. |
| `status` | 2 | **Post-Race Leakage (Current Race)** | None for current race | `statusId`, `status` | Describes how the current race ended ("Finished", "Engine", "Collision", etc.). Allowed strictly in historical aggregates. |
| `constructor_results` | 5 | **Post-Race Leakage (Current Race)** | None for current race | `points`, `status` | Records current race constructor points. Must only be used via historical rolling averages prior to race $t$. |
| `constructor_standings` | 7 | **Post-Race Leakage (Current Race)** | Lagged to round $t-1$ | `points`, `position`, `positionText`, `wins` (for current `raceId`) | **Ergast Trap:** Standings in this table are updated *after* `raceId`. Joining on `raceId` leaks current race points! Must be lagged to previous round. |
| `driver_standings` | 7 | **Post-Race Leakage (Current Race)** | Lagged to round $t-1$ | `points`, `position`, `positionText`, `wins` (for current `raceId`) | **Ergast Trap:** Standings in this table are updated *after* `raceId`. Must be lagged to previous round. |
| `lap_times` | 6 | **In-Race Telemetry (100% Leakage)** | None for current race | `lap`, `position`, `time`, `milliseconds` | In-race lap-by-lap telemetry. Completely forbidden for current race. |
| `pit_stops` | 7 | **In-Race Events (100% Leakage)** | None for current race | `stop`, `lap`, `time`, `duration`, `milliseconds` | In-race pit stop events. Completely forbidden for current race. |
| `sprint_results` | 16 | **Conditional Pre-Race (Modern Era)** | If included, must be prefixed with `sprint_` | Raw un-prefixed columns (`position`, `points`, `laps`, etc.) | Sprint race occurs on Saturday before Sunday Grand Prix. Must prefix all features (e.g. `sprint_position`) to prevent collision with Sunday `results`. Exists only $\ge 2021$. |
